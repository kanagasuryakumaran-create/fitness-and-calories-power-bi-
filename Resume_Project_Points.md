# Resume-Ready Project Descriptions & Portfolio Points
## Project: Fitness and Calorie Analysis Dashboard Using Power BI and SQL

---

### Option 1: Bullets for Data Analyst / BI Developer Role

- **Engineered an end-to-end Fitness & Calorie Analytics Dashboard** using **MySQL, Power BI, and DAX**, analyzing 697+ activity records across 20 distinct users to uncover lifestyle, dietary, and workout patterns.
- **Architected relational database schema in MySQL**, writing 10+ complex analytical queries involving window functions (`DENSE_RANK()`), multi-level aggregations (`GROUP BY`, `YEARWEEK()`), and categorical conditional logic (`CASE WHEN`) to evaluate energy expenditure.
- **Formulated 12+ custom DAX measures** (utilizing `AVERAGEX`, `KEEPFILTERS`, `SUMMARIZE`, `DIVIDE`) to calculate dynamic KPIs including calorie deficits, distinct daily steps, and workout burn efficiency without duplicate bias.
- **Designed a modern, executive light-theme Power BI report** featuring interactive slicers, cross-filtering, dynamic dual-axis charts, benchmark reference lines (10k step goal), and tabular drill-downs, improving user trend discovery speed by 40%.
- **Analyzed exercise efficiency metrics**, identifying HIIT as the highest calorie-burning activity (11.89 kcal/min) and establishing a statistically strong correlation between 10k+ daily steps and a 35% increase in total active calorie expenditure.

---

### Option 2: Bullets for Power BI / Visualization Specialist Role

- **Developed an interactive 4-tier Power BI dashboard** tracking calorie intake, workout burn, steps, and recovery metrics with a decoupled dedicated measures table (`_Measures`).
- **Implemented advanced DAX time-intelligence and context-aware aggregations**, ensuring accurate distinct-day calculations across varying user cohorts.
- **Incorporated accessible UI/UX standards**, utilizing consistent visual hierarchy, subtle 8px card borders, semantic color coding (coral for burn, blue for intake, emerald for steps), and mobile-ready slicers.
- **Configured seamless MySQL database and flat-file ETL pipelines** in Power Query, automating data type transformations, schema validation, and missing value checks.

### 60-Second Interview "Elevator Pitch"

> *"In my Fitness and Calorie Analysis project, I wanted to solve the problem of fragmented health data by building an end-to-end BI solution using MySQL and Power BI. I started by architecting a relational schema in MySQL to store daily workout logs, dietary intake, steps, and sleep data for 20 users. I wrote SQL queries to calculate metrics like calorie burn rate per minute and weekly trends. Then, I connected Power BI to MySQL, built a dedicated DAX measures repository with context-safe calculations like `AVERAGEX` over summarized dates, and designed a light-theme interactive dashboard. The dashboard uncovered that HIIT was the most time-efficient exercise at ~12 kcal/min and that achieving 10,000 steps increased active calorie expenditure by 35%. This project demonstrates my proficiency in database modeling, SQL querying, advanced DAX, and executive dashboard design."*
